# Data directory

This project does not use any external or empirical dataset. All
data are simulated. This file replaces a prior template README that
documented a Palmer Penguins dataset never present in this
repository (2026-08-16 review, issue 2.8(d)); that content was a
zzcollab scaffold artifact left over from project creation and did
not describe this project.

## Directory structure

```
data/
  raw_data/       # empty; no raw data are used by this project
  derived_data/   # simulation output, generated by
                   # analysis/scripts/run_simulation.R
```

## Derived data (`derived_data/`)

| File               | Generating script                     | Description |
|--------------------|----------------------------------------|--------------|
| `sim_results.rds`  | `analysis/scripts/run_simulation.R`    | Paired Monte Carlo simulation results (raw per-replication estimates, summary statistics with Monte Carlo standard errors, analytic GLS standard errors, and a bootstrap interval for the relative efficiency of the two visit designs) comparing the equal-spacing and boundary-clustered five-visit schedules. |

To regenerate:

```bash
Rscript analysis/scripts/run_simulation.R 2000
```

The report (`analysis/report/report.Rmd`) reads `sim_results.rds`
via inline `r` expressions rather than hardcoding simulation output
in prose, so the manuscript cannot desynchronize from the underlying
data.
